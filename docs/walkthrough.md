# 短时复核路径

环境准备和镜像构建在操作前完成。服务的健康入口是 `/health`；服务启动即继续，不固定等待。正常本地启动在数秒内完成。若90秒内没有就绪，应停止操作并保留错误，不把等待算作成功运行。

从首页选择一个研究结果，先看“跨研究整合”中每个量表的总体效应、区间与研究中位数；若只有一个量表可合并，其他量表会明确标为“不可合并”。展开“每项贡献与原始组别”，核对每项研究的权重、所用时间点，以及干预组和对照组的 `arm_id`、`cohort_id`、样本量、均值与标准差。

再查看“未进入合并的研究”：`not_reported`（已声明未报告）、`missing_record`（缺少记录）与 `no_dispersion`（未报告离散程度）含义不同，都不当作零效应。展开“报告完整性”可比较每个研究已报告、已声明未报告与缺记录的条目数，并核对每项原始比较的状态。

展开“敏感性分析”，逐项核对：留一研究后总体估计的变化；把可疑重复报告全部纳入或全部剔除的差异；替换研究内比较后的结果；不同报告完整性策略与重复测量相关假设的影响。若使用“范围内全部时间点”，页面会提示相关性是假设值，并列出不同假设下的结果。

选择研究组别的原始比较表格中的一行，使用“查看原始记录”核对字段。输入会议名称并保存，然后改变所选范围；点击左侧刚保存的记录核对先前材料仍能打开，最后导出当前记录。整段交互通常需要45至75秒，不依赖远程请求。

`fixtures/data.json` 可用于重新导入核对。页面说明的是观测和适用范围；不要为了演示修改数据以制造某种优胜、显著性或异常结论。新增加的分析也应从真实可用证据解释结果，不要求出现某个指定方向。若某量表只剩一项研究或全部被重叠剔除，页面会如实显示“不可合并”，这本身就是要复核的结论。
