# 数据口径

arms 标识实际组别统计；相同 arm_id 被不同 comparison 引用仍是同一组。cohorts 列出每个组别的样本成员集合，交集代表重叠；数据均为虚构编号。outcomes 中 scale_id 与 direction 定义量表及高低含义；declared 但未 reported 的结果不是零。means 中 sd=null 表示未报告离散程度。correlations 给出已知或仅可假设的相关范围，不提供唯一合并算法。

## 数据版本

`fixtures/data.json` 是可直接导入的一份完整材料，`product.json` 保存页面默认范围。导入必须提交完整对象，不把省略字段解释为删除补丁；以规范化 JSON 的 SHA-256 标识内容，同内容多次导入复用版本。原始记录只追加版本，保存的分析材料始终指向原来版本。

页面中的范围影响当前描述，不回写源数据。`null`、缺记录与实际零不能合并；数据格式问题应在导入时明确报错，而不是生成看似成功的空结果。涉及单位、时间或关系的解释以本文件为准，统计方法和业务决策没有预设结果。

## 跨研究整合口径

`evidence_synthesis/synthesis.py` 把“能合并”与“只能并列”分开处理，不假设唯一的合并方法。

- **合并单位**：一项研究在所选范围内只贡献一个比较。研究内多个比较共用对照时不能同时计入，按所选规则取第一个或最后一个，并列出替换结果。
- **合并条件**：同一结果、同一量表、同一时间窗口，处理组与对照组都报告均值与离散程度（`reported=true` 且 `sd` 非空），且该研究在窗口内没有“已声明未报告”的位置。任一条件不满足就只并列呈现，并保留具体原因（`not_reported`、`missing_record`、`no_dispersion`、`zero_variance`、`scale_conflict`、`scale_mixed`、`incomplete_reporting`）。
- **量表**：`scale_id` 不同的研究分别合并；没有换算依据时不产生跨量表的总平均数。
- **重复证据**：同一 cohort 的成员出现在两项研究的实际比较组别中即为重叠。`independent`（主分析，按研究编号依次保留互不重叠者）、`all`（全部纳入，会重复计权）与 `strict`（剔除任何重叠研究）三种处理都展示，使用者可见结论依赖。
- **未报告与零**：`not_reported` 与 `missing_record` 都不进入任何平均数，也不补零。`available_case` 策略只是放宽完整性要求，不会把缺失值当成零。
- **研究间差异**：给出 Cochran Q、I²、tau² 与随机效应；研究数 ≥3 时给出基于 t 分布的研究间预测区间。固定效应与随机效应并列，不默认其中一个是唯一答案。
- **重复测量相关性**：`latest` 策略每项研究只取一个时间点，不需要该假设；`all_weeks` 把多个时间点写入同一研究效应，使用 `correlations.same_arm_repeated`。`known=false` 时该值是假设而非观测，页面按范围（含中点）逐一列出，也允许输入 0–1 的假设做比较。假设变化会改变标准误，但不表示相关性已被测量。
- **敏感性**：留一研究、可疑重复报告（全部纳入 / 全部剔除 / 当前策略）、研究内比较规则、报告完整性策略、相关假设都会重算并并列；`robustness` 只汇总这些变体的方向与显著性是否稳定，不挑选有利结果。
- **适用范围**：每组的 `applicability` 报告纳入研究、队列、参与人数、时间点与方向解释；超出同一量表与时间窗口时只能并列，不能外推。

数值函数（Q 的卡方尾概率、t 临界值）用标准库实现，已在测试中与参考值核对。没有引入第三方运行依赖。

## 目录

`evidence_synthesis/domain.py` 提供领域校验和描述，`validation.py` 处理基础引用与数值校验，`synthesis.py` 实现跨研究整合与敏感性，`service.py` 连接领域操作和材料存档，`storage.py` 负责内容寻址数据与历史记录，`server.py` 提供本地接口。`web/app.js` 使用接口构建交互页面，不自行推导独立口径。
